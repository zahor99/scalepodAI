How it works
Seven steps, each with a named gate
One conversation per brief. The agent does the work; the designer, the account manager or the client decides at each gate. Nothing paid runs before you see the cost.
01

Client intake

Scrape the client's site plus uploaded guidelines and confirm the brand kit: logo, palette, tone. Flags a missing vector logo before it bites.

Gate: designer confirms
02

Concept board

Brief to 3–5 directions. Each product is mapped to a blank in the supplier catalogue, with a hero render and an indicative price per product.

Gate: designer picks
03

Steer and select

"Direction 2, left chest, small, navy tee." Placement and scale are parsed from plain language and only the affected items re-render.

Iterative, as many rounds as you need
04

Print pack

A 300 dpi PNG per print position to the supplier template, supplier mockups and a rules file. Optional check against Printify.

Gate: designer approves, 6-point checklist
05

Studio shots

Studio and lifestyle images from presets and slots, each with a QA score, for the deck and the review page.

No gate
06

Client review

A magic-link page the client opens on a phone, no login. Accept, reject or regenerate per item. Decisions resume the run at the right step.

Gate: client decides
07

Quote and deck

Supplier tiers, decoration, shipping and VAT assumptions feed a cost table and a deck as HTML and PDF, ready to send.

Gate: designer sends
+

Supplier catalogue
Print files only on verified blanks
Suppliers disagree on print areas and leave out shipping, prices or millimetres. So the catalogue has two tiers, and only one of them may produce a print file.
verified

Verified blank

Print-area template confirmed against the supplier's spec, one test render and one test print file checked, price tiers and shipping captured with a date, confirmation questions answered.

  • Shown on the board, usable by any brief
  • Print files and mockups allowed
  • v1 set: bottle, notebook, pen, tote, backpack, tee, cap across Yoycol, PeaPrint and Printify
candidate

Candidate blank

Parsed from the supplier page or API, not yet checked. Fine for discovery and pricing conversations; never for a print file.

  • Proposed only when flagged "needs verification"
  • No print file until an operator promotes it
  • Promotion is a one-blank onboarding with a recorded date
A brief asking for a product outside the verified catalogue gets not in the catalogue yet, I can queue it for onboarding, never a guess.
